        GitHub

        Sign in with GitHub

        Create one OAuth app, then Connect GitHub sends you to GitHub. After that, Friday can open repositories you own, ones shared with you, organization repos, and any public project.

        1. Create an OAuth app. Homepage http://127.0.0.1:5000. Callback http://127.0.0.1:5000/api/github/callback.
        2. Put the client id and secret in .env as GITHUB_CLIENT_ID and GITHUB_CLIENT_SECRET.
        3. Restart Friday, then click Connect GitHub again.
